## What this does not cover

- Only step 1 (question to intent). Whether `_execute_query` returns the right rows for a correct intent, and the written summary (step 3), are not scored.
- Single questions only: follow-ups that rely on conversation history are not tested.
- Questions whose right answer is debatable are left out on purpose, so the set is easier than real traffic.
- One run at the production temperature (0.1), so a re-run can differ by a case or two.
- 45 hand-written questions on the demo data; this is a regression check, not a measure of accuracy on real users' questions.
